## Descripción

Luna-Botv6 permite descargar contenido multimedia desde las plataformas más populares directamente desde WhatsApp.

---

## Facebook

Descargá videos de Facebook enviando el enlace del video.

### Comando

```
.fb [enlace]
```

**Ejemplo:**
```
.fb https://www.facebook.com/watch?v=123456789
```

---

## TikTok

Descargá videos de TikTok sin marca de agua.

### Comando

```
.tiktok [enlace]
```

**Ejemplo:**
```
.tiktok https://www.tiktok.com/@usuario/video/123456789
```

---

## YouTube — Música

Buscá y descargá una canción de YouTube en formato de audio. No necesitás el enlace, solo el nombre de la canción o artista.

### Comando

```
.play [nombre de la canción]
```

**Ejemplo:**
```
.play Bad Bunny Tití Me Preguntó
.play Shakira Waka Waka
```

---

## Resumen de comandos

| Plataforma | Comando | ¿Necesita enlace? |
| ---------- | ------- | ----------------- |
| Facebook | `.fb [enlace]` | ✅ Sí |
| TikTok | `.tiktok [enlace]` | ✅ Sí |
| YouTube | `.play [nombre]` | ❌ No, solo el nombre |

:::note
La velocidad de descarga depende del tamaño del contenido y de la conexión del servidor. Para videos muy largos puede tardar algunos segundos.
:::
