## Reconectar el Bot

Si el bot se desconecta de WhatsApp, seguí estos pasos **en orden**:

1. **Apagá el bot** completamente antes de hacer cualquier cambio.
2. Entrá a la carpeta `files` del proyecto.
3. Localizá la carpeta **`Mysticssecion`**.
4. **Borrala por completo.**
5. Iniciá el bot nuevamente con **Start**.
6. Escaneá el código QR para vincular tu cuenta de WhatsApp.

---

## Problema con Descargas

Si el bot no descarga música ni video, es porque no tiene acceso a la API de descargas.

**Solución:** Contactá al creador del bot para solicitar acceso a la API correspondiente.
