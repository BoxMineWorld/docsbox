## Descripción

Estos comandos controlan los mensajes automáticos de bienvenida y despedida dentro de los grupos.

## Comandos

| Función | Comando | Descripción |
| ------- | ------- | ----------- |
| `WELCOME` | `.enable welcome` | Activa el mensaje de bienvenida cuando alguien entra al grupo. |
| `BYE` | `.enable bye` | Activa el mensaje de despedida cuando alguien sale del grupo. |
| `AFK` | `.enable afk` | Controla el uso del modo Ausente (Away From Keyboard). |

## Nota

Para desactivar cualquier función, reemplaza `.enable` por `.disable` seguido del mismo nombre.

**Ejemplo:**
```
.disable welcome
.disable bye
.disable afk
```
