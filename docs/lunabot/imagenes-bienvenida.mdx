## Descripción

Cada grupo puede tener su propia imagen personalizada para los mensajes de entrada y salida.

## Configurar imagen

1. Enviá la imagen que querés usar en el grupo.
2. Respondé esa imagen con el comando correspondiente:

| Comando | Descripción |
| ------- | ----------- |
| `.imgwelc` | Asigna la imagen de bienvenida al grupo. |
| `.imgbye` | Asigna la imagen de despedida al grupo. |

## Eliminar imagen

Para volver a usar la foto de perfil del usuario como imagen:

| Comando | Descripción |
| ------- | ----------- |
| `.delwelcimg` | Elimina la imagen de bienvenida personalizada. |
| `.delbyeimg` | Elimina la imagen de despedida personalizada. |

## Nota

- Solo los **administradores del grupo** pueden usar estos comandos.
- Cada grupo tiene su propia imagen independiente.
