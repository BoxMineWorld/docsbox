## Descripción

Podés cambiar la imagen o el video que aparece al ejecutar el comando de menú.

Enviá `.menu` en el chat para ver tus estadísticas y las instrucciones disponibles.

## Comandos

| Comando | Descripción |
| ------- | ----------- |
| `.Imgmenu` | Enviá la imagen que querés usar como menú y respondela con este comando para asignarla. |
| `.Vidmenu` | Enviá el video/gif (máx. 5 segundos) que querés usar como menú y respondelo con este comando. |

## Cómo usarlo

**Para cambiar por una imagen:**
1. Enviá la imagen en el chat.
2. Respondé esa imagen con `.Imgmenu`.

**Para cambiar por un video/gif (máx. 5 segundos):**
1. Enviá el video o gif en el chat.
2. Respondé ese video con `.Vidmenu`.

## Nota

El cambio se aplica de forma global para todos los grupos y usuarios del bot.
