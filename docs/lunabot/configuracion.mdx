## Cambiar Nombre del Bot

Podés reemplazar el nombre predeterminado **"Luna-Botv6"** por el nombre que prefieras. El cambio se refleja en el menú, comandos, IA y todos los plugins.

### Comando

```
.setnamebot [NombreNuevo]
```

**Ejemplo:**
```
.setnamebot MiBot
```

---

## Configurar Idioma

Luna-Botv6 tiene soporte multi-idioma. Podés cambiar el idioma del bot con los siguientes comandos:

| Comando | Idioma |
| ------- | ------ |
| `.idioma es` | Español *(idioma por defecto)* |
| `.idioma pt` | Portugués |
| `.idioma en` | Inglés |

### Nota

La IA continúa mejorando el soporte multi-idioma. Algunos comandos pueden no estar disponibles en todos los idiomas todavía.
