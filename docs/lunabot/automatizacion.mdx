## Descripción

Funciones automáticas relacionadas con contenido multimedia y comportamiento del bot.

## Comandos

| Función | Comando | Descripción |
| ------- | ------- | ----------- |
| `AUTOREAD` | `.enable autoread` | Marca automáticamente como leídos todos los mensajes. *(Solo Owner)* |
| `AUDIOS` | `.enable audios` | Activa o desactiva la respuesta automática con audios. |
| `AUDIOS_BOT` | `.enable audios_bot` | Activa o desactiva los audios del propio bot. *(Solo Owner)* |
| `AUTOSTICKER` | `.enable autosticker` | Convierte automáticamente imágenes o videos en sticker. |
| `VIEWIMAGE` | `.enable viewimage` | Activa la vista previa de imágenes enviadas al bot. *(Solo Owner)* |

## Nota

Las funciones marcadas como **(Solo Owner)** solo pueden activarse o desactivarse por el dueño del bot.

Para desactivar cualquier función, reemplaza `.enable` por `.disable` seguido del mismo nombre.

**Ejemplo:**
```
.disable autoread
.disable autosticker
```
